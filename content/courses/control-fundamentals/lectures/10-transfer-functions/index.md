## Визначення

{{< callout type="info" title="Передатна функція" >}}
Перетворення Лапласа імпульсної характеристики системи:
$$G(s) = \mathcal{L}\{h(t)\}.$$
{{< /callout >}}

Подамо на вхід імпульс — у s-області це просто одиниця, $\mathcal{L}\{\delta(t)\} = 1$. На виході отримаємо саму передатну функцію.

{{< figure src="definition.webp" alt="G(s) = ℒ{h(t)}; у часі δ(t) → система → h(t); у s-області 1 → G(s) → G(s)" >}}

## Візок із пружиною й демпфером

Візок прикріплений до стіни пружиною (жорсткість $k$) і демпфером (коефіцієнт $b$). До візка прикладаємо силу $F(t)$ — це вхід; вихід — положення $x(t)$. Запишемо сили за другим законом Ньютона:

$$
m\ddot{x} + b\dot{x} + kx = F(t).
$$

- $m\ddot{x}$ — інерція (маса × прискорення);
- $b\dot{x}$ — опір демпфера, пропорційний швидкості;
- $kx$ — сила пружини, пропорційна зміщенню.

Це диференціальне рівняння другого порядку. Щоб знайти імпульсну характеристику, треба подати імпульс і розв'язати рівняння в часі — довго й громіздко. Простіше перейти в s-область.

{{< figure src="cart-equation.webp" alt="Візок m між пружиною k і демпфером b; сила F — вхід, положення x — вихід; m·ẍ + b·ẋ + k·x = F(t), ДР 2-го порядку; графік затухаючих коливань x(t)" >}}

## З диференціального рівняння — в алгебраїчний дріб

Перетворення Лапласа типових виразів давно пораховані й зібрані в таблиці:

| Час | s-область |
|---|---|
| $\delta(t)$ | $1$ |
| $x(t)$ | $X(s)$ |
| $\dot{x}(t)$ | $s\,X(s) - x(0)$ |
| $\ddot{x}(t)$ | $s^2 X(s) - s\,x(0) - \dot{x}(0)$ |

{{< figure src="laplace-table.webp" alt="Таблиця перетворень Лапласа: δ(t) → 1, x(t) → X(s), ẋ → s·X(s) − x(0), ẍ → s²·X(s) − s·x(0) − ẋ(0)" >}}

Візок стартує зі стану спокою, тож $x(0) = 0$ і $\dot{x}(0) = 0$. Подаємо імпульс і замінюємо кожен член рівняння:

$$
m s^2 X + b s X + k X = 1
\;\;\Rightarrow\;\;
X(s)\,(ms^2 + bs + k) = 1.
$$

Диференціальне рівняння стало **алгебраїчним**. Ділимо:

$$
\boxed{\;G(s) = \frac{1}{ms^2 + bs + k}\;}
$$

Це передатна функція візка.

{{< figure src="equation-to-fraction.webp" alt="m·ẍ + b·ẋ + k·x = δ(t) → m·s²X + b·sX + k·X = 1 → X(s)·(ms² + bs + k) = 1 → G(s) = 1/(ms² + bs + k); d/dt → × s; ділення в s ⇔ обернена згортка в t" >}}

Зверніть увагу:

- **похідна** в s-області — це просто **множення на $s$**, інтеграл — ділення на $s$;
- просте ділення на $(ms^2 + bs + k)$ у s-області відповідало б громіздкій «оберненій згортці» в часі.

## Сходинка, інтегратор 1/s і перевірка

Тепер можна подавати на вхід будь-яку силу, яку вдається записати в s-області, і множити її на передатну функцію. Що буде, якщо силу не прикласти ударом, а ввімкнути й тримати, тобто подати **сходинку**?

Сходинка — це інтеграл від імпульсу: площа імпульсу 1, тож інтеграл стрибає до 1 і далі не змінюється. У s-області:

$$
\mathcal{L}\{\text{сходинка}\} = \frac{1}{s}.
$$

{{< figure src="step-integral.webp" alt="Імпульс δ(t) площею 1; його інтеграл — сходинка, що стрибає до 1; ℒ{сходинка} = 1/s" >}}

Отже, $1/s$ — це **інтегратор**. Ставимо його перед візком і просто множимо:

$$
X(s) = \frac{G(s)}{s}.
$$

{{< figure src="integrator.webp" alt="1 (δ(t)) → [1/s] → сходинка → [G(s)] візок; X(s) = G(s)/s — множимо, і все" >}}

Перевіримо на числах: $m = 1$ кг, $b = 1$ Н·с/м, $k = 4$ Н/м, тож

$$
G(s) = \frac{1}{s^2 + s + 4}.
$$

Відгук, отриманий з $G(s)/s$, і чисельне розв'язання рівняння руху (методом Рунге — Кутти) збігаються: візок трохи коливається і зупиняється на **¼ м** — там, де пружина врівноважує силу в 1 Н ($kx = F$, $x = F/k$).

{{< figure src="step-check.webp" alt="m = 1, b = 1, k = 4 → G(s) = 1/(s² + s + 4); графік x(t): формула з G(s)/s і чисельне розв'язання збігаються, різниця < 10⁻¹²; усталення на ¼ м = F/k" caption="Дві криві — з передатної функції і з чисельного розв'язку — лягають одна на одну." >}}

## Вітер → вітрило → візок → радар

Справжня сила передатних функцій — у тому, що складну систему можна зібрати з простих блоків. Нехай візок штовхає не рука, а вітрило, що ловить вітер.

{{< figure src="sail-cart.webp" alt="Візок-яхта з помаранчевим вітрилом, лінії вітру; чоловічок вимірює положення радаром; «складну систему — з простих блоків»" >}}

- Вітрило має свою передатну функцію $S(s)$: вхід — швидкість вітру, вихід — сила на візок.
- Сам вітер теж можна описати функцією $W(s)$.
- Положення візка вимірює радар зі своєю динамікою $R(s)$.

Модель усього ланцюжка — **добуток** передатних функцій блоків:

$$
W(s)\cdot S(s)\cdot G(s)\cdot R(s).
$$

{{< figure src="chain.webp" alt="Вітер W(s) → швидкість вітру → вітрило S(s) → сила → візок G(s) → положення → радар R(s); одна модель W(s)·S(s)·G(s)·R(s)" >}}

Кожен блок може описати окремий фахівець: знавець вітру, конструктор вітрила, інженер візка, розробник радара. Потім моделі просто з'єднуються. Так само кулька над перевернутою чашею: вентилятор, чаша, радар і оцінювач — чотири передатні функції, перемножені в одну.

{{< figure src="puzzle.webp" alt="Четверо чоловічків за столом складають пазл із чотирьох кольорових частин; «кожен блок — свій фахівець»" >}}

## Вихід / вхід

Часто передатну функцію визначають як відношення виходу до входу в s-області:

$$
G(s) = \frac{Y(s)}{U(s)}.
$$

Це дає той самий результат, але пам'ятайте, що стоїть за цим діленням: у часі вихід — згортка входу з імпульсною характеристикою, $y(t) = u(t) * h(t)$.

{{< figure src="output-input.webp" alt="G(s) = Y(s)/U(s) — той самий результат; за лаштунками y(t) = u(t) * h(t)" >}}

## Головне

{{< figure src="summary.webp" alt="G(s) = ℒ{h(t)}; ДР → алгебраїчний дріб, 1/s — інтегратор; блоки в ряд — множення" >}}

- **Передатна функція** $G(s) = \mathcal{L}\{h(t)\}$ — перетворення Лапласа імпульсної характеристики.
- Диференціальне рівняння в s-області стає **алгебраїчним дробом**: похідна — множення на $s$.
- $1/s$ — **інтегратор**; відгук на сходинку — $G(s)/s$.
- Послідовні блоки **перемножуються**.

Далі ми навчимося працювати зі структурними схемами, у яких є зворотний зв'язок.

### Завдання 1. Передатна функція з рівняння

Отримайте передатну функцію $G(s) = Y(s)/U(s)$ за нульових початкових умов:

1. $2\dot{y} + 6y = u$
2. $\ddot{y} + 3\dot{y} + 2y = 4u$
3. $\ddot{y} + 2\dot{y} + 5y = \dot{u} + u$

{{< answer >}}
1. $(2s + 6)Y = U \Rightarrow G(s) = \dfrac{1}{2s + 6}$.
2. $(s^2 + 3s + 2)Y = 4U \Rightarrow G(s) = \dfrac{4}{s^2 + 3s + 2} = \dfrac{4}{(s+1)(s+2)}$.
3. $(s^2 + 2s + 5)Y = (s + 1)U \Rightarrow G(s) = \dfrac{s + 1}{s^2 + 2s + 5}$.
{{< /answer >}}

### Завдання 2. Відгук візка на сходинку — чисельно

Перевірте результат уроку самостійно: змоделюйте візок $m = 1$, $b = 1$, $k = 4$ під дією сталої сили 1 Н простим покроковим методом (крок $dt = 0{,}001$ с) і знайдіть положення через 20 с і найбільше відхилення.

{{< python-exercise

### Завдання 3. Тангаж літака

Треба отримати передатну функцію тангажу літака: вхід — штурвал, вихід — кут тангажу. Пілот не хоче подавати імпульс (смикнути штурвал і відпустити) — це небезпечно. Замість цього він швидко тягне штурвал на себе і тримає, тобто подає **сходинку**. Виміряний тангаж у s-області:

$$
P(s) = \frac{s + 0{,}2}{s^4 + 0{,}7s^3 + s^2}.
$$

1. Яка передатна функція тангажу?
2. Яким був би $P(s)$, якби пілот тягнув штурвал рівномірно (лінійно зростаючий вхід, $1/s^2$)?

{{< answer >}}
1. Вихід на сходинку $P(s) = G(s)\cdot\dfrac{1}{s}$, тож $G(s) = s\,P(s) = \dfrac{s + 0{,}2}{s^3 + 0{,}7s^2 + s}$.
2. $P_{\text{рамп}}(s) = G(s)\cdot\dfrac{1}{s^2} = \dfrac{s + 0{,}2}{s^5 + 0{,}7s^4 + s^3}$.
{{< /answer >}}
