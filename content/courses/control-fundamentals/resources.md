## Першоджерело

Курс побудовано за книгою **Brian Douglas. *The Fundamentals of Control Theory: An Intuitive Approach from the Creator of Control System Lectures on YouTube*. Revision 1.6, 2019.** Книга поширюється безкоштовно на сайті автора: [engineeringmedia.com/books](https://engineeringmedia.com/books).

Відповідність уроків розділам книги:

| Урок | Розділ книги |
|---|---|
| 1. Що таке система | 1.1 |
| 2. Три задачі інженерії керування | 1.2 |
| 3. Розімкнені та замкнені системи | 1.3 |
| 4. Стійкість і перший регулятор | 1.4–1.5 |
| 5. Лінійні стаціонарні системи | 2.1 |
| 6. Дельта-функція та імпульсна характеристика | 2.2 |
| 7. Інтеграл згортки | 2.3 |
| 8. Частотна область і перетворення Фур'є | 2.4–2.5 |
| 9. s-площина і перетворення Лапласа | 2.6 |
| 10. Передатні функції | 2.7 |
| 11. Мова структурних схем | 3.1–3.2 |
| 12. Алгебра структурних схем | 3.3–3.4 |
| 13. Модельно-орієнтоване проєктування і HITL | 3.5 |
